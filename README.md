# Personal Website — CV & Portfolio

A personal portfolio and CV website showcasing my engineering projects, technical capabilities, and personality. Built with modern web technologies and a focus on thoughtful user experience, the site serves as both a professional portfolio and an evolving engineering project.

## Overview

This project brings together my professional experience, engineering work, and personal interests in a single, interactive web experience. Beyond presenting my CV and portfolio, it provides a platform to experiment with modern frontend technologies, explore creative design ideas, and continuously refine my approach to software development.

The goal is to create a website that feels polished, responsive, and personal while maintaining a clean, scalable, and maintainable codebase.

## Tech Stack

The website is built using a modern React ecosystem, with an emphasis on type safety, performance, and reusable components.

* [**React 19**](https://react.dev/) — Component-based UI development.
* [**TanStack Start**](https://tanstack.com/start) — Full-stack React framework and application architecture.
* [**Vite**](https://vite.dev/) — Development server and build tooling.
* [**TypeScript**](https://www.typescriptlang.org/) — Type safety and an improved developer experience.

### Architecture & Development

The application uses a component-driven architecture designed around reusable UI primitives, clear separation of concerns, and type safety. This approach supports maintainability and makes it easier to extend the website as new projects and features are introduced.

Key areas of focus include:

* Reusable and composable UI components.
* Type-safe application development.
* Maintainable project structure.
* Responsive layouts for desktop and mobile devices.
* Accessibility-conscious design and interaction patterns.
* Modern frontend development practices.

## Design & User Experience

Considerable attention has been given to the visual identity and browsing experience of the website. Rather than relying on static layouts alone, the design incorporates motion and interaction to make navigating the portfolio more engaging.

Highlights include:

* Custom animations and transitions.
* Scroll-driven visual effects.
* A progressively evolving visual theme.
* Responsive layouts across screen sizes.
* Consistent visual language and reusable design elements.
* A focus on usability, accessibility, and visual clarity.

The intention is to balance creative expression with functionality, ensuring that the visual experience enhances the content rather than distracting from it.

## AI-Assisted Development

AI-assisted tools played a supporting role throughout the design and implementation process.

Tools used include:

* [**GitHub Copilot**](https://github.com/features/copilot) — Assistance with implementation and repetitive development tasks.
* [**ChatGPT**](https://chatgpt.com/) — Exploring solutions, refining ideas, and supporting technical problem-solving.
* [**Lovable**](https://lovable.dev/) — Rapid prototyping and exploration of design concepts.

These tools were used to accelerate prototyping, explore alternative solutions, and streamline repetitive development tasks. Generated code and components were reviewed, refined, and integrated manually to ensure they aligned with the project's architecture and quality standards.

AI formed part of the development workflow rather than a replacement for engineering judgement, implementation decisions, or code review.

## Project Philosophy

This website is more than a static portfolio; it is an ongoing exercise in engineering, design, and continuous improvement.

One of my professors once remarked that if engineers are left to themselves, they will continue to refine, redesign, and optimise a system in pursuit of perfection.

This project embraces that philosophy.

Not because perfection is attainable, but because every iteration is an opportunity to build something better.

As I explore new technologies, experiment with new ideas, and refine the user experience, the website will continue to evolve alongside my development as an engineer.

## Future Development

The project is designed to accommodate future improvements, including:

* Expanding the engineering project portfolio.
* Refining animations and interactive elements.
* Improving accessibility and performance.
* Exploring additional frontend technologies and design approaches.
* Introducing new features as the portfolio grows.
